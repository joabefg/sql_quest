Bancos de dados servem para armazenar e consultar dados, então antes de consultar qualquer coisa, precisamos primeiro inserir dados nas tabelas do banco de dados.

Professor
O comando INSERT é usado para inserir novas informações. Para usá-lo precisamos saber o nome da tabela, dos campos e dos valores a ser inserido. A estrutura básica do comando é:
INSERT INTO tabela (campo1, campo2) VALUES (valor1, valor2);

Professor
Textos são envolvidos por aspas duplas para indicar que são textos. Caso fosse inserir a classe, seria da forma abaixo, use como modelo para ajudar a inserir seu nome de aventureiro:
INSERT INTO classe (tipo) VALUES ("Humano");
